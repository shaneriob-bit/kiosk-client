To add backgrounds, 
go to %appdata%/Godot/kiosk-client(I believe I used the backgrounds folder from the original)
create a directory called backgrounds 
adding a folder to this directory will make an image
adding images to the sub directories will add backgrounds

To add previews,
go to go to %appdata%/Godot/kiosk-client
create a directory called previews
add images to the directory to add backgrounds
